# Money Manager Frontend

Modern React-based web application for managing personal and business finances with intuitive UI and powerful analytics.

## 🌐 Live Demo

**Application URL**: https://money-manager-frontend-ci9s.onrender.com

**API Backend**: https://money-manager-backend-jcrf.onrender.com

## 🎯 What We Built

A responsive financial management dashboard with transaction tracking, multi-account support, real-time balance updates, and comprehensive reporting visualizations.

## 💡 Problem & Solution

**Problem**: Managing finances is complex without proper visualization, filtering, and insights into spending patterns across multiple accounts.

**Solution**:
- Visual dashboard with income/expense charts
- Easy transaction creation with category icons
- Account-based transaction filtering
- Real-time balance tracking
- Personal vs Office separation
- Mobile-responsive design

## ✨ Key Features

- 📊 Interactive Dashboard
  - Weekly/Monthly/Yearly summaries
  - Income vs Expense trends
  - Recent transactions

- 💳 Account Management
  - Multiple account types
  - Click to view account transactions
  - Real-time balance display

- 📝 Transaction Management
  - Quick add modal with tabs
  - Category selection with icons
  - Personal/Office division
  - 12-hour edit/delete window
  - Advanced filtering

- 📈 Reports & Analytics
  - Category breakdown charts
  - Division-based analysis
  - Spending trends
  - Custom date ranges

- 🎨 Modern UI/UX
  - Tailwind CSS styling
  - Responsive design
  - Loading states
  - Toast notifications
  - Icon system (Lucide)

## 🛠️ Tech Stack

- React 18
- React Router v6
- Tailwind CSS
- Axios (API calls)
- Recharts (visualizations)
- Lucide React (icons)
- React Hot Toast (notifications)
- date-fns (date formatting)
- Vite (build tool)
